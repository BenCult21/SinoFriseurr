# SinoFriseurr

Eine moderne Lösung für Friseursalons und Barbershops.

## Features

- Terminverwaltung
- Kundenverwaltung
- Dienstleistungsmanagement
- Abrechnung und Reporting

## Installation

```bash
npm install
```

## Verwendung

```bash
npm start
```

## Tests

Um die Tests auszuführen:

```bash
npm test
```

### Test-Struktur

Die Test-Suite deckt folgende Bereiche ab:

- **Unit Tests**: Tests für einzelne Funktionen und Module
- **Integration Tests**: Tests für die Zusammenarbeit mehrerer Komponenten
- **E2E Tests**: End-to-End Tests für komplette Workflows

### Test-Ausführung

```bash
# Alle Tests ausführen
npm test

# Tests mit Coverage
npm test -- --coverage

# Tests im Watch-Mode
npm test -- --watch

# Spezifische Test-Datei
npm test -- path/to/test.js
```
